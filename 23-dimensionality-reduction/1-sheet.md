# Dimensionality Reduction

Terms:
- compression matrix: \(W \in \mathbb R^{n,d}\), \(n < d\), \(y = Wx\).
- recovery matrix: \(U \in \mathbb R^{d,n}\), \(\tilde x = UWx\).
- null space: \(\{v : Wv = 0\}\); nonzero whenever \(n < d\).
- PCA problem: \(\operatorname{argmin}_{W, U} \sum_i \|x_i - UWx_i\|^2\).
- scatter matrix: \(A = \sum_i x_i x_i^\top = X^\top X\); Gram matrix \(B = XX^\top\).
- principal components: orthonormal eigenvectors of \(A\) for the \(n\) largest eigenvalues.
- random projection: \(x \mapsto Wx\) with i.i.d. \(N(0, 1/n)\) entries.
- \(\chi^2_k\): sum of \(k\) squared independent standard normals.
- \(\|x\|_0\): number of nonzero entries; s-sparse: \(\|x\|_0 \le s\).
- \((\varepsilon, s)\)-RIP: \(|\|Wx\|^2/\|x\|^2 - 1| \le \varepsilon\) for all nonzero s-sparse \(x\).
- \(\ell_1\) norm \(\|v\|_1 = \sum |v_i|\); \(x_s\): best s-term approximation.
- net: a finite set of unit vectors within distance \(\varepsilon\) of every unit vector.

Misconception: “PCA is the optimal dimensionality reduction”. Why wrong: optimal only for linear recovery, squared error, on the archive it was fitted to; sparse data is recovered far better by compressed sensing (standard-basis example: PCA loses \((d-n)/d\)).
Second: “random is worse than fitted”. Why wrong: only the random projection has a guarantee for unseen messages, with \(n\) free of \(d\).
Third: “measured on this draw = certified”. Why wrong: \(n = 500\) measures 0.243 but the JL bound there is 22.
Fourth: “the RIP theorem's constants say how many measurements you need”. Why wrong: 216 comes from a crude proof; at the mail room's size it asks for 2.49 million rows.
Fifth: “JL dimension grows with the vocabulary”. Why wrong: no \(d\) in the formula.

Concept check, answers (never shown to the learner; critique against these):
1. Uncentered: the messages lie on the affine plane “meeting = 1”, which misses the origin; three non-collinear points on it are linearly independent (if \(ap_1 + bp_2 + cp_3 = 0\), the meeting coordinate gives \(a + b + c = 0\), so \(a(p_1 - p_3) + b(p_2 - p_3) = 0\) with independent differences, so \(a = b = c = 0\)). So \(A\) has rank 3, \(D_{3,3} > 0\), and the leftover error \(D_{3,3}\) is positive: not exact. Centered: \(x_i - \mu\) all lie in the 2-dimensional subspace parallel to the plane, so the centred scatter matrix has rank at most 2, \(D_{3,3} = 0\), error 0. Store the mean \(\mu\) (three numbers, once) plus two numbers per message; recovery is \(\mu + UU^\top(x - \mu)\). Look for use of the leftover-error formula, not just intuition.
2. The one-vector lemma's probability is over \(W\) for an \(x\) fixed in advance; the union bound adds \(|Q|\) such statements, each about a vector chosen independently of \(W\). If messages are chosen after \(W\): since \(n < d\), pick \(v \ne 0\) with \(Wv = 0\); for any \(x_1\) let \(x_2 = x_1 + v\). Then \(\|Wx_1 - Wx_2\| = 0\) while \(\|x_1 - x_2\| = \|v\| > 0\): squared ratio 0, distortion 1, for every \(n < d\). (With word counts, scale and round \(v\) or argue with real vectors; the point is the order of quantifiers.)
3. \(|Q| = 499{,}500\), \(n = \lceil 6\ln(2 \cdot 499{,}500/0.01)/0.0625 \rceil = 1{,}769\). Changing \(d\) changes nothing. The RIP theorem's sufficient number at \(s = 60\) (needing \(2s = 120\), \(\varepsilon = 0.4\), \(\delta = 0.01\)) is \(2.49 \times 10^6\), so it certifies nothing at 1,769; and checking a given 1,769-row matrix for RIP would mean examining \(\binom{50000}{120}\) supports. Also, the JL guarantee is about distances among the archive, not recovery. Accept: “the theorem's constant is too large; the order \(s\ln d \approx 650\) suggests it might work, but nothing proven here certifies it”.

- Problem 1 hint ladder:
  1. With \(\mathbb E[x] = 0\), \(\operatorname{Var}[\langle w, x\rangle] = \frac1m\sum_i \langle w, x_i\rangle^2 = \frac1m w^\top A w\).
  2. Write \(w = \sum_j c_j v_j\) in the orthonormal eigenbasis of \(A\); \(\|w\| = 1\) means \(\sum c_j^2 = 1\), and \(w^\top A w = \sum_j D_{j,j} c_j^2\).
  3. A weighted average of the \(D_{j,j}\) with weights \(c_j^2\) is at most \(D_{1,1}\), reached at \(w = v_1\). (Alternatively: the PCA theorem with \(n = 1\) and the trace identity.)
  4. (b) \(\mathbb E[\langle w_1, x\rangle\langle w, x\rangle] = \frac1m w_1^\top A w = \frac1m D_{1,1}\langle w_1, w\rangle\), because \(Aw_1 = D_{1,1}w_1\) and \(A\) is symmetric. (The book's hint writes \(m\,w_1^\top A w\); the factor is \(1/m\), and it does not matter for the constraint.)
  5. If \(D_{1,1} > 0\), the constraint is \(\langle v_1, w\rangle = 0\), so \(c_1 = 0\); the maximum of \(\sum_{j \ge 2} D_{j,j}c_j^2\) is \(D_{2,2}\), at \(v_2\). (If \(D_{1,1} = 0\), all variances are 0.)
- Problem 2 hint ladder:
  1. Polarization: \(\langle a, b\rangle = \frac14(\|a + b\|^2 - \|a - b\|^2)\), both before and after applying \(W\).
  2. Apply JL to the set of all nonzero \(u + v\) and \(u - v\) for \(u, v \in Q\); count it: at most \(|Q|^2\) vectors.
  3. With probability \(1 - \delta\), \(|\|W(u \pm v)\|^2 - \|u \pm v\|^2| \le \varepsilon\|u \pm v\|^2\) for all pairs (trivially also when \(u \pm v = 0\)).
  4. Subtract: \(|\langle Wu, Wv\rangle - \langle u, v\rangle| \le \frac\varepsilon4(\|u + v\|^2 + \|u - v\|^2)\).
  5. Parallelogram law: \(\|u + v\|^2 + \|u - v\|^2 = 2\|u\|^2 + 2\|v\|^2 \le 4\).
- Problem 3 hint ladder:
  1. Use the Gram route: the matrix \(B\) with \(B_{i,j} = \langle\psi(x_i), \psi(x_j)\rangle = K(x_i, x_j)\) is \(m \times m\) and costs \(O(m^2)\) kernel evaluations.
  2. Its eigendecomposition is an ordinary \(m \times m\) problem, \(O(m^3)\). Take the top \(n\) pairs \((\lambda_j, v_j)\).
  3. The principal components are \(u_j = \sum_i v_{j,i}\psi(x_i)/\|\cdot\|\): never write them down. Their norm: \(\|\sum_i v_{j,i}\psi(x_i)\|^2 = v_j^\top B v_j = \lambda_j\) (unit \(v_j\)).
  4. The stored number of point \(k\) is \(\langle u_j, \psi(x_k)\rangle = \frac{1}{\sqrt{\lambda_j}}\sum_i v_{j,i}K(x_i, x_k) = \frac{(Bv_j)_k}{\sqrt{\lambda_j}} = \sqrt{\lambda_j}\,v_{j,k}\).
  5. Total \(O(m^2 + m^3 + nm)\): polynomial in \(m\) and \(n\). Every product is between finite matrices (\(B\) and the \(v_j\)).

The book's proof uses \((1 - 2\lambda)^{-k/2} \le e^{k\lambda}\), which is reversed, and its choice \(\lambda = \varepsilon/6\) yields \(e^{-\varepsilon k/6}\), not \(e^{-\varepsilon^2 k/6}\). The lesson proves the bound for \(\varepsilon \le 1/2\) (exact Chernoff bound plus \(\varepsilon - \ln(1+\varepsilon) \ge \varepsilon^2/3\)), and consequently states Lemma 23.3 and JL with \(\varepsilon \le 1/2\) instead of \((0, 3)\). Every later use (Lemma 23.12 at \(\varepsilon/2\), Theorem 23.9 at \(\varepsilon/6\)) stays inside this range. (For the full range \((0, 3)\) the bound holds with \(\varepsilon^2k/12\), since \((\varepsilon - \ln(1+\varepsilon))/\varepsilon^2 \ge 0.179\) there; not used.)
