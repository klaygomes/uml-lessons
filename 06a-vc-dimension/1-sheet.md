# The VC Dimension

Objective: after this, you can compute the restriction of a class to a finite set, decide whether a class shatters it, prove the VC dimension of thresholds (1), intervals (2), axis-aligned rectangles (4), finite classes (at most log2 |H|) and unions of intervals (infinite); prove that infinite VC dimension rules out PAC learning; state the fundamental theorem of statistical learning in both versions and prove its easy arrows; run ERM for thresholds and intervals in O(m log m); and certify a label budget for thresholds and intervals on the score line. The hard arrow (finite VC dimension gives uniform convergence) is lesson 6b.

Terms:
- spam score: a number in [0, 1] the scoring service assigns a message; the domain is now \(\mathcal X = [0, 1]\).
- threshold: \(h_t(x) = \mathbb 1[x > t]\), \(\mathcal H_{\mathrm{thr}} = \{h_t : t \in \mathbb R\}\).
- restriction: \(\mathcal H_C = \{(h(c_1), \dots, h(c_m)) : h \in \mathcal H\}\), the labellings \(\mathcal H\) produces on \(C\).
- shatter: \(\mathcal H\) shatters \(C\) when \(|\mathcal H_C| = 2^{|C|}\).
- VC dimension: the size of the largest set \(\mathcal H\) shatters; infinite if there is no largest.
- fundamental theorem of statistical learning: six equivalent properties (UC, ERM agnostic PAC, agnostic PAC, PAC, ERM PAC, finite VC), and the quantitative bounds in \(d\).
- tightest interval: the realizable learner returning \([x_{\min}, x_{\max}]\) over the junk examples.

Misconception 1: “an infinite class cannot be learned”. Why wrong: thresholds are infinite and PAC learnable with \(\lceil \log(2/\delta)/\varepsilon \rceil\) examples; VC dimension, not size, decides.
Misconception 2: “VCdim ≥ d needs every d-set shattered”. Why wrong: one shattered set suffices; the universal quantifier belongs to the upper bound (every d+1 set fails).
Misconception 3: “VC dimension = number of parameters”. Why wrong: \(\lceil 0.5\sin(\theta x)\rceil\) has one parameter and infinite VC dimension.

Concept check, answers (never shown to the learner; critique against these):
1. {always keep, always junk}: on one point both labellings occur, so one point is shattered; on two points only (0,0) and (1,1), so no pair is shattered: VC dimension 1, equal to \(\log_2 |\mathcal H| = 1\) (the finite-class bound is tight here). Thresholds with t ∈ [0, 1] on [0, 1]: \(h_t(0) = \mathbb 1[0 > t] = 0\) for every \(t \ge 0\), so {0} is not shattered; every \(\{c\}\) with \(0 < c \le 1\) is (t = 0 gives junk, t = c gives keep). No pair is shattered (the (1, 0) argument is unchanged). VC dimension 1: one shattered set suffices. Look for the quantifier asymmetry stated explicitly.
2. VC = 4: any 4 points, every labelling has at most 2 runs of junk, so realizable by at most two intervals (one per run); 5 points \(c_1 < \dots < c_5\), labelling (1,0,1,0,1) has 3 runs, impossible (a single interval covering two junk points covers the keep point between them, so each interval covers at most one run). Look for both halves: one shattered set of size 4 (any 4 distinct points work), and an argument for every 5-point set, not one example.
