# Decision Trees

Objective: after this, you can define a decision tree over yes/no features and read its paths as rules; prove that threshold trees with \(k\) leaves shatter \(k\) points (so unrestricted trees are not PAC learnable) and state why trees over \(\{0,1\}^d\) have VC dimension \(2^d\); build the prefix-free preorder code with \((n+1)\lceil\log_2(d+3)\rceil\) bits, prove it prefix-free, and derive the description-length bound for trees from lesson 7b's MDL bound; run ID3 with training-error, information-gain and Gini gains, state its cost, and prove that the smooth gains are concave upper bounds of the training error that never go blind the way training error does; prune a tree bottom-up with the bound; reduce real-valued threshold splits to yes/no features (with proof) and find the best threshold in \(O(dm\log m)\); define a random forest and say what it costs in time and in readability.

Key words: decision tree (short form "tree"; not "rule tree", "classifier"), root, internal node, leaf, splitting rule (the test \(\mathbb 1[x_i = 1]\) or \(\mathbb 1[x_i < \theta]\) at a node; not "condition", "test" as a term), "yes" child / "no" child (not "left" / "right"; the book says left and right), path (root to leaf; read as a rule), rule (plain word for a path read as a sentence; never for the hypothesis as a whole), size \(n\) (number of nodes, internal and leaves; not "complexity"), depth (internal nodes on the longest path; "levels" = depth + 1, used once to match the book's "height"), block (one \(\lceil\log_2(d+3)\rceil\)-bit unit of the code), preorder, open slots (the decoding counter), description language, description length \(|h|\), prefix-free, MDL (from lesson 7b, used as there), bound / certificate (bound = the right-hand side; "certificate" is the story word for a bound an auditor can rely on, as in lessons 10b and 11), gain (not "score", "impurity decrease"), training error (the book's "train error"; only as the name of the gain \(C(a) = \min\{a,1-a\}\), never for \(L_S\) of a hypothesis, which stays empirical risk), information gain, entropy, Gini index, concave / strictly concave, ID3, greedy, prune / pruning (not "trim"), threshold (not "cutoff"), random forest (not "ensemble" as a term; "vote" as in lesson 10a), resample (the book's "subsample with replacement"; not "bootstrap" in prose), message, feature, junk / keep (labels 1 / 0 again), example, training sequence (not "training set"), hypothesis, empirical risk, true risk, VC dimension, shatter, accuracy \(\varepsilon\) (never \(\epsilon\)), confidence \(\delta\), sample size \(m\).

Terms:
- decision tree: finite rooted binary tree, internal nodes labelled by \(i \in [d]\) with "yes" (\(x_i = 1\)) and "no" (\(x_i = 0\)) children, leaves labelled in \(\{0,1\}\); predicts by walking root to leaf (p. 250, p. 251).
- size \(n\) and depth: nodes; internal nodes on the longest root-to-leaf path. Every internal node has two children, without loss of generality (footnote 1, p. 252).
- threshold splitting rule: \(\mathbb 1[x_i < \theta]\), \(i \in [d]\), \(\theta \in \mathbb R\) (p. 251).
- tree code: \(n + 1\) blocks of \(b = \lceil\log_2(d+3)\rceil\) bits, nodes in preorder then an end block; block options: internal node \(\mathbb 1[x_i = 1]\) (\(d\) of them), leaf 1, leaf 0, end (pp. 251 to 252).
- \(\mathbb P_S\): probability under the uniform distribution over the examples of \(S\) (p. 253).
- Gain\((S, i) = C(\mathbb P_S[y=1]) - (\mathbb P_S[x_i=1]\,C(\mathbb P_S[y=1 \mid x_i=1]) + \mathbb P_S[x_i=0]\,C(\mathbb P_S[y=1 \mid x_i=0]))\), with \(C(a) = \min\{a, 1-a\}\) (training error), \(-a\log a - (1-a)\log(1-a)\) (information gain, entropy), \(2a(1-a)\) (Gini index) (pp. 253 to 254).
- ID3\((S, A)\) (p. 253); generic pruning procedure (p. 254); threshold features \(\mathbb 1[x_i < \theta_{j,i}]\), \(\theta_{j,i} \in (x_{j,i}, x_{j+1,i})\) (p. 255).
- random forest: majority vote over trees grown by \(A\) on \(S\) and i.i.d. random vectors \(\theta\); the book's choice: resample \(S'\) of size \(m'\) from \(S\) with replacement, subsets \(I_t \subseteq [d]\) of size \(k\), ID3 restricted at each split to \(I_t\) (pp. 255 to 256).

Misconception: "ID3 finds the best tree." Why wrong: it is greedy; minimizing the bound is NP-hard (if P ≠ NP), and Problem 2 shows depth-2 ID3 stuck at training error 1/4 where a depth-2 tree has 0.
Second misconception: "zero empirical risk means a good tree." Why wrong: on noisy mail, full ID3 trees memorize the noise: true risk about 0.22 against a floor of 0.1, bound near 0.9.
Third misconception: "pruning with the bound uses the data twice, so the certificate is void." Why wrong: the bound holds for every tree simultaneously and the code is fixed before \(S\); only a data-dependent code would void it.
Fourth misconception: "training error is the natural gain." Why wrong: its gain is exactly 0 for every split that leaves both majorities on the same side; about half of random splits (49,934 of 100,000).

Derivation (all proofs are in the prose):
- Threshold trees with \(k\) leaves shatter \(k\) points: chain tree with midpoints (p. 251 states it; the chain construction is ours). Infinite VC dimension, not PAC learnable (lesson 6a).
- Trees over \(\{0,1\}^d\) express every function, VC dimension \(2^d\): stated, proof left to Problem 1 (p. 251 defers it to Exercise 1).
- Tree code prefix-free: end block appears only last (proper prefixes); open-slot counter for injectivity, by induction (the book says "it is not hard to show", p. 252; proof ours). Functions described by a smallest tree with a fixed tie rule (ours; the book treats trees as hypotheses directly).
- Description-length bound \(L_{\mathcal D}(h) \le L_S(h) + \sqrt{((n+1)b + \log(2/\delta))/(2m)}\) from Theorem 7.7 (Equation 18.1, p. 252, with \(\log_2(d+3)\) unrounded).
- Gain proposition: upper bounds (Gini by \(1 - a \ge 1/2\); entropy by concavity between \(H(0) = 0\) and \(H(1/2) = 1\)); all gains \(\ge 0\) by concavity and the law of total probability; strict positivity for entropy and Gini by strict concavity (second derivatives \(-4\) and \(-1/(a(1-a)\ln 2)\)); training-error gain exactly 0 when \(p_1, p_0\) on the same side of 1/2. The book only states "smooth and concave upper bounds" (p. 254); the proofs and the blindness statement are ours.
- Threshold reduction: same shape, nodes and training labels (p. 255 says "easy to verify"; proof ours).

Algorithms:
- ID3 (p. 253): \(O(md^2)\) time (gain by four counts, \(O(md)\) per level, depth \(\le d\)), \(O(md)\) space (at most \(m/2\) internal nodes per level), \(O(d)\) prediction. Ties: argmax toward lowest index, majority toward 1 (our convention; the book leaves ties open). Empty child: leaf 1 vacuously (the book's pseudocode, literally).
- Generic pruning (p. 254) with the bound as \(f\): \(O(n(md + n))\) time; the unchanged tree preferred on ties (ours). Implementation in `ref.py`: postorder walk, "yes" subtree first.
- BestThreshold sort-and-sweep: \(O(m\log m)\) per feature, \(O(dm\log m)\) per node, against the naive \(O(dm^2)\) (p. 255 states both costs; the sweep pseudocode is ours, modelled on lesson 10a's stump ERM).
- Random forest (pp. 255 to 256): \(O(Tm'kd)\) training, \(O(Td)\) prediction.
- Build-it challenge: `gain`, `id3`, `nodes`, `encode`, `tree_bound`, `prune`, `thresholds`; asserts (tiny tree 7 nodes and 24 bits; seed-0 \(m = 300\) full tree 107 nodes; pruned 7 nodes; bound rounds to 0.37; 7 thresholds for the hours) all pass with `ref.py` (`solution.py`). Forest build-it: `forest`, `vote`; reference: forest disagreement with \(f\) 0.0047 on 4,000 fresh messages (seed 99), single tree 0.1542; assert `< 0.05` and `> 0.1` passes (`fcheck.py`; forest rng `random.Random(7)`, 25 trees, \(k = 10\)).

Concept check, answers (never shown to the learner; critique against these):
1. All gains are 0 at every node (both examples have the same message). Root: F (lowest index); "yes" (\(x_F = 1\)) gets both examples; "no" is empty, so a leaf 1 (vacuous first test). Next L: message has \(x_L = 0\), so the "yes" child is empty (leaf 1) and "no" gets both. Then U ("yes" both, "no" empty leaf 1), then N ("yes" both, "no" empty leaf 1), then \(A = \emptyset\): majority, a tie, leaf 1. Tree: 4 internal nodes and 5 leaves, all labelled 1: \(n = 9\), 30 bits, \(L_S = 1/2\). No tree can do better than 1/2: the two examples have the same message and different labels, and any hypothesis gives that message one label. Pruning with the bound returns a single leaf (the reference returns leaf 1; leaf 0 ties), 6 bits, bound 2.056 against 3.402 for the 9-node tree (both vacuous at \(m = 2\)). Look for: vacuous leaves, the irreducible 1/2, and that ID3 grows useless nodes when gains are all 0.
2. The description-length bound holds on one event of probability at least \(1 - \delta\) for every tree simultaneously, so it holds for the tree pruning picks, whatever rule picked it. The code depends only on \(d\), fixed before \(S\). Dropping unused features after seeing \(S\) makes the language a function of \(S\): the weights \(2^{-|h|}\) used in the MDL proof (via SRM over singletons with \(w(h) = 2^{-|h|}\)) would be chosen after the data, so the bad events in the union bound are not the ones budgeted, and the step "apply lesson 7b's MDL bound to a language fixed in advance" fails (lesson 7b's commit-order warning). Accept: "the union bound's events must be fixed before sampling".
3. 11 nodes: 12 blocks of 5 bits = 60 bits, bound \(0.08 + \sqrt{(60 + \log 40)/3000} = 0.2257\); 7 nodes: 40 bits, \(0.10 + \sqrt{(40 + \log 40)/3000} = 0.2207\). The 7-node tree wins by 0.005. The 11-node tree wins when \((\sqrt{63.689} - \sqrt{43.689})/\sqrt{2m} < 0.02\), i.e. \(m > 2{,}348.7\): from \(m = 2{,}349\) on (bounds 0.19643 each at that \(m\), 11-node strictly smaller). Look for: blocks = nodes + 1, natural log in \(\log(2/\delta)\).

End-of-chapter problems (Section 18.6, PDF pp. 256 to 257, both exercises; the chapter has only two). In the prose: Problem 1 = Exercise 1, Problem 2 = Exercise 2. Hints one rung at a time; never the solution.
- Exercise 1 (any Boolean function is a tree; VC dimension \(2^d\)), standard.
  1. Try \(d = 1\) and \(d = 2\) by hand. What is the shape of a tree that asks every feature on every path?
  2. Induction on \(d\): split on \(x_1\); each branch fixes \(x_1\) and leaves a function of \(d - 1\) features. What does the induction hypothesis give you for each branch?
  3. The full tree has \(2^d\) leaves, one per message, so writing \(h(x)\) into the leaf of \(x\) computes \(h\). For the VC dimension: the class realizes every labelling of \(\{0,1\}^d\), so it shatters the whole domain (\(\ge 2^d\)), and no class shatters more points than the domain has (\(\le 2^d\)).
  Note for the critique: the book says "height at most \(d + 1\)", counting levels of nodes; the prose says depth \(d\), that is \(d + 1\) levels. Accept either with the counting made explicit.
