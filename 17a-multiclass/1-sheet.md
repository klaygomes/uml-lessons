Terms:
- one-versus-all: train \(h_i\) on \(S_i\) (label \(+1\) iff \(y = i\)); predict \(\operatorname{argmax}_i h_i(\mathbf x)\), ties by smallest index or real-valued confidences.
- all-pairs: \(h_{i,j}\) on examples of \(i\) and \(j\); predict \(\operatorname{argmax}_i \sum_j \operatorname{sign}(j - i) h_{i,j}(\mathbf x)\).
- class-sensitive feature mapping \(\Psi: \mathcal X \times \mathcal Y \to \mathbb R^d\); predictor \(h_{\mathbf w}(\mathbf x) = \operatorname{argmax}_y \langle \mathbf w, \Psi(\mathbf x, y) \rangle\); class \(\mathcal H_{\Psi, W}\).
- multivector: \(\Psi(\mathbf x, y)\) has \(\mathbf x\) in block \(y\) of \(k\) blocks; \(\langle \mathbf w, \Psi(\mathbf x, y) \rangle = \langle \mathbf w_y, \mathbf x \rangle\).
- TF-IDF: \(\Psi_j(\mathbf x, y) = \mathrm{TF}(j, \mathbf x) \log(m/\mathrm{DF}(j, y))\), DF counted in training messages not about \(y\).
- cost \(\Delta(y', y) \ge 0\), \(\Delta(y, y) = 0\); risks \(L_S\), \(L^\Delta_{\mathcal D}\).
- generalized hinge loss \(\ell(\mathbf w, (\mathbf x, y)) = \max_{y'} (\Delta(y', y) + \langle \mathbf w, \Psi(\mathbf x, y') - \Psi(\mathbf x, y) \rangle)\).
- structured output: \(\Psi = \frac1r \sum_t \phi(\mathbf x, y_t, y_{t-1})\), type 1 and type 2 entries, \(d = nq + q^2\); \(M_{s,\tau}\) and its recursion.
- certified folder cost: measured users’ cost on \(m_t\) fresh messages plus \(\sqrt{\log(2/\delta)/(2m_t)}\).

Misconception: “if every yes/no filter is optimal, the combination is optimal”. Why wrong: in the three-disc world every filter is the best halfspace for its own question, yet one-versus-all misfiles all work mail (20%), while three weight vectors classify perfectly.
Second: “ties are a corner case”. Why wrong: with yes/no filters every work message is a three-way tie; scores, not signs, make ties rare.
Third: “the generalized hinge is one hinge per class”. Why wrong: it is one maximum over all labels, with a margin that scales with each confusion’s cost.
Fourth: “many labels need many examples”. Why wrong: the multiclass SVM and SGD bounds have no explicit \(|\mathcal Y|\); it enters only through \(\rho\) and \(B\) (Remark 17.3).

Concept check, answers (never shown to the learner; critique against these):
1. All scores are 0, so every label ties and \(h_{\mathbf 0}\) returns whatever the tie rule picks. \(\ell(\mathbf 0, (\mathbf x, y)) = \max_{y'} \Delta(y', y)\), the worst cost for that correct label. The bound holds for any tie rule because Step 1 only uses that the predicted label’s score is at least the correct label’s, which is true (with equality) for every label here; and \(\Delta(h_{\mathbf 0}(\mathbf x), y) \le \max_{y'} \Delta(y', y)\) trivially. Work message: \(\max(0, .5, .5, 1) = 1\); promotion: 0.2. Look for: the learner noting that \(\ell\) at \(\mathbf w = 0\) is the worst-case cost, so SGD starts from a loss that already charges every rival.
2. (a) Only the line \(t_2 = (t_1 + t_3)/2\) changes: with work at \((-2, 5) = 0.7(-5,5) + 0.3(5,5)\), \(t_2 = 0.7t_1 + 0.3t_3\), still a convex combination, so \(\max(t_1, t_3) \ge t_2\) and the conclusion survives (discs still disjoint: distance 3 > 2). (b) The halfspace \(x_1 > -2.5\) (says yes to work and promotions) has error 0.25 < 0.5. The proof needs \(p_1 g(t_1) + p_3 g(t_3) \ge p_2 g(t_2)\); a sufficient condition is \(\min(p_{\text{personal}}, p_{\text{promotions}}) \ge p_{\text{work}}\), since then error \(\ge p_2 + (\min(p_1, p_3) - p_2) g(t_2) \ge p_2\). Look for: the learner locating exactly the step \(0.4(g_1 + g_3) \ge 0.4 g_2 \ge 0.2 g_2\).

End-of-chapter problems (Section 17.8, PDF pp. 248 to 249). In the prose they appear as the lesson’s own Problems 1 and 2: Problem 1 = Exercise 1, Problem 2 = Exercise 2 (Theorem 17.5). Hints one rung at a time; never the solution.
- Exercise 1 (balls), standard.
  1. Write each example as \(\mathbf x = \boldsymbol\mu_y + \mathbf v\) with \(\|\mathbf v\| \le r\). What must you show about the scores for \(\ell = 0\) with the zero-one cost?
  2. Try \(\mathbf w_i = [\boldsymbol\mu_i, -\|\boldsymbol\mu_i\|^2/2]\) (the book’s own hint). Compute \(\langle \mathbf w_i, (\mathbf x, 1) \rangle\) and complete the square: \(\frac12\|\mathbf x\|^2 - \frac12\|\mathbf x - \boldsymbol\mu_i\|^2\).
  3. So the score gap of \(y\) over \(i\) is \(\frac12(\|\mathbf x - \boldsymbol\mu_i\|^2 - \|\mathbf x - \boldsymbol\mu_y\|^2)\). Bound \(\|\mathbf x - \boldsymbol\mu_i\| \ge \|\boldsymbol\mu_i - \boldsymbol\mu_y\| - r \ge 3r\) and \(\|\mathbf x - \boldsymbol\mu_y\| \le r\): gap \(\ge 4r^2 \ge 4 \ge 1\). Where is \(r \ge 1\) used? (Checked numerically in `cc.py`: worst hinge 0.0 over 20,000 points.)
- Exercise 2 (multiclass Perceptron), standard; mirrors lesson 9’s mistake bound.
  1. Track \(\langle \mathbf w^\star, \mathbf w^{(t)} \rangle\): each update adds \(\langle \mathbf w^\star, \Psi(\mathbf x_i, y_i) - \Psi(\mathbf x_i, y) \rangle \ge 1\), so after \(T\) updates it is at least \(T\).
  2. Track \(\|\mathbf w^{(t)}\|^2\): expand; the cross term \(2\langle \mathbf w^{(t)}, \Psi(\mathbf x_i, y_i) - \Psi(\mathbf x_i, y) \rangle \le 0\) by the update condition, so the square grows by at most \(R^2\): \(\le TR^2\).
  3. Cauchy–Schwarz: \(T \le \|\mathbf w^\star\| \sqrt T R\), so \(T \le (R\|\mathbf w^\star\|)^2\).
  4. When it stops, no pair violates: \(\langle \mathbf w^{(t)}, \Psi(\mathbf x_i, y_i) \rangle > \langle \mathbf w^{(t)}, \Psi(\mathbf x_i, y) \rangle\) for all \(y \neq y_i\), so \(y_i\) is the unique argmax.
