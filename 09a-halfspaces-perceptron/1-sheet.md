# Halfspaces and the Perceptron

Objective: after this, you can define affine and homogeneous linear functions and the bias-term trick, define halfspaces \(HS_d = \operatorname{sign} \circ L_d\), write ERM for separable data as a linear program (with the rescaling to \(y_i \langle \mathbf w, \mathbf x_i \rangle \ge 1\)), run the Perceptron and prove its \((RB)^2\) mistake bound, read \(B\) as one over the best margin and certify an update count with any separator, and prove that the VC dimension of homogeneous halfspaces is \(d\) and of halfspaces with a bias term is \(d + 1\), each with its time and space cost.

Terms:
- affine function \(h_{\mathbf w, b}(\mathbf x) = \langle \mathbf w, \mathbf x \rangle + b\); class \(L_d\).
- bias-term trick: \(\mathbf w' = (b, \mathbf w)\), \(\mathbf x' = (1, \mathbf x)\), \(\langle \mathbf w', \mathbf x' \rangle = \langle \mathbf w, \mathbf x \rangle + b\).
- halfspace: \(\mathbf x \mapsto \operatorname{sign}(\langle \mathbf w, \mathbf x \rangle + b)\); \(HS_d = \operatorname{sign} \circ L_d\); \(\operatorname{sign}(0) = -1\).
- signed score \(y \langle \mathbf w, \mathbf x \rangle\); separable: some halfspace has \(y_i \langle \mathbf w, \mathbf x_i \rangle > 0\) for all \(i\).
- linear program: \(\max \langle \mathbf u, \mathbf w \rangle\) s.t. \(A \mathbf w \ge \mathbf v\).
- Perceptron update: \(\mathbf w^{(t+1)} = \mathbf w^{(t)} + y_i \mathbf x_i\) on an example with \(y_i \langle \mathbf w^{(t)}, \mathbf x_i \rangle \le 0\).
- radius \(R = \max_i \|\mathbf x_i\|\); \(B = \min\{\|\mathbf w\| : y_i \langle \mathbf w, \mathbf x_i \rangle \ge 1 \ \forall i\}\); margin \(\gamma_{\mathbf u} = \min_i y_i \langle \mathbf u, \mathbf x_i \rangle\), \(\|\mathbf u\| = 1\); \(B = 1/\gamma^\star\).
- shatter, VC dimension (reminded from lesson 6a).

Misconception: “the Perceptron needs about \((RB)^2\) updates”. Why wrong: it is an upper bound over every order; on the eight messages the bound is 142.3 and the run takes 3.
Second misconception: “any separator certifies \((RB)^2\)”. Why wrong: a separator \(\mathbf u\) certifies \((R/\gamma_{\mathbf u})^2 \ge (RB)^2\); \((-1, 2, -2)\) certifies 189, \((-0.5, 1.5, -1)\) certifies 294.
Third misconception: “halfspaces are always easy to learn”. Why wrong: agnostic ERM for halfspaces is computationally hard (book p. 119, Ben-David and Simon 2001); hence surrogate losses (lesson 9b’s logistic regression).
Fourth misconception: “the bias term is the inductive bias”.

Derivation:
- Bias-term trick (pp. 117 to 118); halfspaces and geometry (p. 118); VC \(d + 1\) gives sample complexity (book: \(\Omega((d + \log(1/\delta))/\varepsilon)\), p. 118; the prose quotes the fundamental theorem’s two-sided realizable bound, Theorem 6.8, with VC dimension \(d + 1\)).
- LP: rescaling by \(\gamma = \min_i y_i \langle \mathbf w^\star, \mathbf x_i \rangle\) to (9.1), \(A_{i,j} = y_i x_{i,j}\), \(\mathbf v = \mathbf 1\), \(\mathbf u = \mathbf 0\) (pp. 119 to 120).
- Perceptron identity \(y_i \langle \mathbf w^{(t+1)}, \mathbf x_i \rangle = y_i \langle \mathbf w^{(t)}, \mathbf x_i \rangle + \|\mathbf x_i\|^2\); Theorem 9.1 via (9.2) to (9.5): telescoping \(\ge T\), \(\|\mathbf w\|^2 \le TR^2\), Cauchy–Schwarz (proved inline). The prose takes any feasible \(\mathbf w^\star\) and then the infimum, so existence of the minimizer is not needed.
- Theorems 9.2 and 9.3; linear dependence of \(d + 1\) vectors in \(\mathbb R^d\) (Appendix C level fact, stated, not proved).

Algorithms: HalfspaceLP (build \(A\) in \(O(mn)\), polynomial-time solver, book footnote p. 119); Perceptron (\(O(n)\) space, \(O(mn)\) per update scan, at most \((RB)^2\) updates, \(O(mn(RB)^2)\) total; never stops on non-separable data). The starter’s asserts pass against the reference `bi_ref.py` (run by substituting its implementations; the LP vertex solver finds \((-1, 2, -2)\) on the eight messages and `None` on the ten).

Concept check, answers (never shown to the learner; critique against these):
1. \(\mathbf x = (0,0)\) has \(y \langle \mathbf w, \mathbf x \rangle = 0 \le 0\) for every \(\mathbf w\), so it is always a mistake; the update adds \(y \mathbf x = \mathbf 0\), \(\mathbf w\) never changes, and (with first-mistake order, once H is the first mistake, or under any rule that keeps choosing it) the loop never ends; a careless implementation spins forever. The sequence is not separable by homogeneous halfspaces: no \(\mathbf w\) has \(y \langle \mathbf w, \mathbf 0 \rangle > 0\); the set in the definition of \(B\) is empty (\(B = \infty\) by convention), so the theorem’s hypothesis fails and it promises nothing. Fix: keep the constant 1 (bias term). Look for: the theorem is not violated, its assumption is.
2. Step 2 uses \(y_i \langle \mathbf w^{(t)}, \mathbf x_i \rangle \le 0\) to drop the cross term. Step 1 never uses the mistake condition, so it holds for the variant: \(\langle \mathbf w^\star, \mathbf w^{(T+1)} \rangle \ge T\). In Step 2 the cross term is now \(< 2\), so \(\|\mathbf w^{(t+1)}\|^2 \le \|\mathbf w^{(t)}\|^2 + R^2 + 2\), giving \(\|\mathbf w^{(T+1)}\|^2 \le T(R^2 + 2)\). Step 3: \(T \le \|\mathbf w^\star\| \sqrt{T(R^2 + 2)}\), so \(T \le B^2(R^2 + 2)\). On the eight messages: \(B^2(R^2+2) = 155.9\) against \((RB)^2 = 142.3\); the variant also stops after 3 updates there, at \((-1, 2, -2)\) (`cc.py`). When it stops, every example has \(y_i \langle \mathbf w, \mathbf x_i \rangle \ge 1\). (Not in the book; the margin Perceptron is a common variant.)
3. Signed scores of \((-3, 5, -4)\): 12, 3, 9, 2, 6, 7, 5, 3, all positive, minimum 2 (message D). \(\|\mathbf w\|^2 = 50\), \(R^2 = 21\): bound \(21 \cdot 50 / 4 = 262.5\). Worse than 189 and than 142.3. Hand over \((-1, 2, -4/3)\) (142.3) if you can find it, else \((-1, 2, -2)\); the smaller certificate is a stronger promise and both are valid. Look for: scale invariance (dividing by the minimum score) and that every valid certificate is an upper bound, none is “wrong”.

End-of-chapter problems (Section 9.6, PDF pp. 128 to 129). In the prose: Problem 1 = Exercise 3, Problem 2 = Exercise 6 (part 2 starred). Exercise 1 (absolute loss as LP) went to lesson 9b. Hints one rung at a time; never the solution.
- Exercise 3 (tightness of the mistake bound), standard.
  1. Try \(d = m\), \(\mathbf x_i = \mathbf e_i\), all labels \(+1\). What is \(R\)?
  2. Which \(\mathbf w^\star\) has \(\langle \mathbf w^\star, \mathbf e_i \rangle \ge 1\) for every \(i\) and \(\|\mathbf w^\star\|^2 = m\)? So \((RB)^2 \le m\).
  3. Run the Perceptron by hand: after updating on \(\mathbf e_1, \dots, \mathbf e_k\), what is \(\langle \mathbf w, \mathbf e_{k+1} \rangle\)? Why does every example need its own update? (Then \(T = m \ge (RB)^2\), so in fact \((RB)^2 = m\).)
- Exercise 6 (balls), part 1 standard, part 2 starred. Uses \(\operatorname{sign}(0) = +1\) as the book states for this exercise; the prose says so.
  1. Expand \(\|\mathbf x - \mathbf v\|^2 \le r^2\). Which terms involve \(\|\mathbf x\|^2\), which are linear in \(\mathbf x\), which are constant?
  2. Write it as \(\langle (2\mathbf v, -1), (\mathbf x, \|\mathbf x\|^2) \rangle + (r^2 - \|\mathbf v\|^2) \ge 0\): a halfspace with a bias term in \(\mathbb R^{d+1}\). So shattering by balls implies shattering of the lifted points by \(HS_{d+1}\), whose VC dimension is \(d + 2\).
  3. (Part 2) Put the points on the unit sphere. For \(\|\mathbf x\| = 1\), ball membership becomes \(\langle \mathbf v, \mathbf x \rangle \ge c\) with \(c = (\|\mathbf v\|^2 + 1 - r^2)/2\). Which \(c\) can you reach with \(r > 0\)?
  4. Choose \(d + 1\) affinely independent points on the sphere (for example the vertices of a regular simplex). Then \((1, \mathbf x_i)\) are linearly independent, so for any target values you can solve for \((-c, \mathbf v)\) exactly; pick targets \(\pm 1\) and scale \(\mathbf v\) up so \(r > 0\).
- Not chosen: Exercise 2 (lesson 9b’s pseudo-inverse proof essentially contains it), Exercise 4 (starred tight example in \(\mathbb R^3\); offer later), Exercise 5 (scaling the update by \(\eta\); good follow-up to concept check 2).
