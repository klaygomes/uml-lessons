Terms:
- embedding: a map \(\psi: \mathcal X \to \mathcal F\) into a Hilbert space; its range is the feature space.
- image sequence \(\hat S = ((\psi(x_i), y_i))_i\); image distribution \(\mathcal D_\psi(A) = \mathcal D(\{(x, y) : (\psi(x), y) \in A\})\); \(L_{\mathcal D_\psi}(h) = L_{\mathcal D}(h \circ \psi)\).
- Hilbert space: vector space with an inner product, complete (Cauchy sequences converge).
- kernel: \(K(x, x') = \langle \psi(x), \psi(x') \rangle\); Gram matrix \(G_{i,j} = K(x_i, x_j)\).
- representer theorem: for \(\min_{\mathbf w} f(\langle \mathbf w, \psi(x_1) \rangle, \dots, \langle \mathbf w, \psi(x_m) \rangle) + R(\|\mathbf w\|)\), \(R\) nondecreasing, some optimum is \(\sum_i \alpha_i \psi(x_i)\).
- kernel trick: learning and prediction via \(G\) and \(K\) only; soft-SVM: \(\min_{\boldsymbol\alpha} \lambda \boldsymbol\alpha^\top G \boldsymbol\alpha + \frac1m \sum_i \max\{0, 1 - y_i (G\boldsymbol\alpha)_i\}\); predict \(\sum_j \alpha_j K(x_j, x)\).
- polynomial kernel \((1 + \langle \mathbf x, \mathbf x' \rangle)^k\), embedding into \(\mathbb R^{(n+1)^k}\) by ordered tuples; Gaussian kernel \(e^{-\|\mathbf x - \mathbf x'\|^2/(2\sigma)}\), infinite-dimensional embedding.
- positive semidefinite: \(\boldsymbol\alpha^\top G \boldsymbol\alpha \ge 0\) for all \(\boldsymbol\alpha\); a symmetric \(K\) is a kernel iff all its Gram matrices are positive semidefinite.
- reproducing property: \(\langle f, K(\cdot, x) \rangle = f(x)\) on \(V = \operatorname{span}\{K(\cdot, x)\}\).
- KernelSGD-SoftSVM: \(\boldsymbol\alpha^{(t)} = \boldsymbol\beta^{(t)}/(\lambda t)\); on \(y_i \sum_j \alpha_j^{(t)} K(x_j, x_i) < 1\), \(\beta_i \mathrel{+}= y_i\); output \(\bar{\boldsymbol\alpha} = \frac1T \sum_t \boldsymbol\alpha^{(t)}\).
- margin bound (from lesson 15): with \(\|\psi(x)\| \le \rho\) and a separator of norm \(B\) with margin 1 everywhere, soft-SVM with \(\lambda = \sqrt{2\rho^2/(B^2 m)}\) has \(\mathbb E[L^{0-1}_{\mathcal D}] \le \sqrt{8\rho^2 B^2/m}\); labels for \(\varepsilon\): \(m \ge 8\rho^2 B^2/\varepsilon^2\).

Misconception: “the kernel trick makes the feature space small”. Why wrong: the space is unchanged (possibly infinite); storage and computation move to \(m\) coefficients and the \(m \times m\) Gram matrix (2.048 GB at \(m = 16{,}000\)).
Second misconception: “any similarity function is a kernel”. Why wrong: \(\max\{x, x'\}\) on \(\{1, 2\}\) has Gram \([[1,2],[2,2]]\) and \((1,-1)\) gives \(-1\).
Third misconception: “the Gaussian kernel can separate anything, so it is a safe default”. Why wrong: as \(\sigma \to 0\) it becomes the memorizer, with \(B^2 = N\) over \(N\) messages (concept check 1); on pair-marked junk the best Gaussian certificate the writer found needs \(1.85 \times 10^8\) labels.
Fourth misconception: “the representer theorem means few training messages matter”. Why wrong: it gives a combination of all \(m\); sparsity comes from the loss (support vectors, hard-SVM).

Derivation (all in the prose with proofs):
- Embedding paradigm and \(L_{\mathcal D_\psi}(h) = L_{\mathcal D}(h \circ \psi)\).
- Representer theorem: Gram–Schmidt projection, Pythagoras, \(R\) nondecreasing, data term unchanged; remark: strictly increasing \(R\) forces every optimum into the span.
- Kernel trick: scores and norm in \(\boldsymbol\alpha\); Equation 16.3 and the soft-SVM form 16.4; prediction.
- Polynomial kernel expansion over \(J \in \{0..n\}^k\); Gaussian kernel via the exponential series.
- Characterization: easy direction \(\boldsymbol\alpha^\top G\boldsymbol\alpha = \|\sum \alpha_i \psi(x_i)\|^2\); converse on \(V = \operatorname{span}\{K(\cdot,x)\}\) with well-definedness, bilinearity, reproducing property, Cauchy–Schwarz for semidefinite forms, definiteness; completion mentioned.
- Lemma (kernel SGD equals feature-space SGD): induction on \(\boldsymbol\theta^{(t)} = \sum_j \beta_j^{(t)} \psi(x_j)\), coupled random choices.
- Margin bound for kernels: Corollary 15.7 with hinge 0, AM-GM for \(\lambda\), \(\rho^2 = \max K(x,x)\), \(B^2\) via the kernel; certificate count \(c_k\) by inclusion and exclusion.

Algorithms: SGD-SoftSVM (recap) and KernelSGD-SoftSVM. Cost: per step \(O(\min(t, m)\, c_K)\) for the test; \(\bar{\boldsymbol\alpha}\) naive \(O(m)\) per step or lazy harmonic-sum settling \(O(1)\) per update plus \(O(m)\); total \(O(T \min(T, m)\, c_K)\); cached Gram \(O(m^2 c_K)\) time, \(O(m^2)\) space, then \(O(m)\) per test; space without cache \(O(m)\) plus the messages; prediction \(O(r\, c_K)\), \(r\) nonzero coefficients. Explicit features: \(O(D)\) per step and space. Concept check, answers (never shown to the learner; critique against these):
1. As \(\sigma \to 0\), \(K(x, x') \to 1\) if \(x = x'\) and 0 otherwise, so \(G \to I_N\). With \(\boldsymbol\alpha = \mathbf y\), \(G\boldsymbol\alpha = \mathbf y\), so \(y_i(G\boldsymbol\alpha)_i = 1\): any labelling is separable. Minimum norm: writing \(\mathbf w = \sum \alpha_i \psi(x_i)\) (representer theorem applies to hard-SVM), \(\|\mathbf w\|^2 = \boldsymbol\alpha^\top I \boldsymbol\alpha = \sum \alpha_i^2\) and the constraints are \(y_i \alpha_i \ge 1\), so the minimum is \(\boldsymbol\alpha = \mathbf y\), \(B^2 = N\), \(B = \sqrt N\). \(\rho = 1\). Labels for \(\varepsilon = 0.2\): \(8N/0.04 = 200N\); for the 1,000-word three-word domain, \(N = 166{,}167{,}000\) and \(200N = 33{,}233{,}400{,}000\), two hundred times the number of possible lines. It is the memorizer of lesson 1: no generalization, only lookup. Accept answers that reason with a finite \(\sigma\) and a limit; check they use the whole domain (not only the training lines) for the certificate.
2. “\(R\) nondecreasing” is used in step two: from \(\|\mathbf w\| \le \|\mathbf w^\star\|\) to \(R(\|\mathbf w\|) \le R(\|\mathbf w^\star\|)\). “Data term only through the scores” is used in step three: \(\langle \mathbf u, \psi(x_i) \rangle = 0\) leaves every argument of \(f\) unchanged. Example: \(R(a) = (a - 1)^2\), \(f(a_1) = a_1^2\), \(\psi(x_1) = (1, 0)\): the objective \(\langle \mathbf w, e_1 \rangle^2 + (\|\mathbf w\| - 1)^2\) is 0 exactly at \(\mathbf w = (0, \pm1)\), which are orthogonal to the span; every vector in the span, \((a, 0)\), has objective \(a^2 + (|a| - 1)^2 \ge 1/2 > 0\). Other valid examples: any \(R\) that strictly decreases somewhere combined with a data term that pins the span component.
3. \(G = [[0, 1], [1, 0]]\) (\(K(\mathbf x_1, \mathbf x_1) = K(\mathbf x_2, \mathbf x_2) = 0\), \(K(\mathbf x_1, \mathbf x_2) = 1\)). \(\boldsymbol\alpha = (1, -1)\): \(0 - 1 - 1 + 0 = -2 < 0\). Not positive semidefinite, so by the characterization no embedding into any Hilbert space has this as its inner product; also visible directly: \(K(\mathbf x_1, \mathbf x_1) = 0\) would force \(\psi(\mathbf x_1) = 0\) and then \(K(\mathbf x_1, \mathbf x_2) = 0 \ne 1\). Bonus: \(-\|\mathbf x - \mathbf x'\|^2\) also fails in general; \(e^{-\|\mathbf x - \mathbf x'\|^2/(2\sigma)}\) is the valid way to turn distance into similarity.

- Problem 2 = Exercise 4 (\(\min\{x, x'\}\) is a kernel).
  1. Write \(\min\{x, x'\}\) as a count: how many integers \(j\) satisfy \(j \le x\) and \(j \le x'\)?
  2. A count of common elements is an inner product of indicator vectors.
  3. \(\psi(x) = (\mathbb 1[1 \le x], \mathbb 1[2 \le x], \dots, \mathbb 1[N \le x]) \in \mathbb R^N\), so \(\langle \psi(x), \psi(x') \rangle = \sum_{j=1}^N \mathbb 1[j \le \min\{x, x'\}] = \min\{x, x'\}\).
  4. Why does \(\max\) fail where \(\min\) works? (Count of \(j \le x\) or \(j \le x'\) is a union, not an intersection.)
- Problem 3 = Exercise 6 (closest class average).

  2. \(\|\psi(x) - \mathbf c_+\|^2 \le \|\psi(x) - \mathbf c_-\|^2 \iff 2\langle \psi(x), \mathbf c_+ - \mathbf c_- \rangle + \|\mathbf c_-\|^2 - \|\mathbf c_+\|^2 \ge 0\); divide by 2. Mind the tie convention (the book’s \(h\) outputs 1/0 and uses \(\le\); sign at 0 must be read as \(+1\)).
