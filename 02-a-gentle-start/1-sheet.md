Terms:
- examples domain \(\mathcal Z = \mathcal X \times \mathcal Y\): all message-and-label pairs.
- loss function \(\ell : \mathcal H \times \mathcal Z \to \mathbb R_+\): scores a hypothesis on one example; here \(\mathbb 1[h(x) \neq y]\). Only introduced; Chapter 3 uses it.
- statistical learning framework: input \(\mathcal X\), \(\mathcal Y\), \(S\); output \(h\); hidden \(\mathcal D\) over \(\mathcal X\) and labelling function \(f\); success measured by \(L_{(\mathcal D, f)}(h)\).
- labelling function \(f\): the unknown correct label of every message, \(y_i = f(x_i)\).
- ERM: return a hypothesis minimizing \(L_S(h)\). \(\mathrm{ERM}_{\mathcal H}(S) \in \operatorname{argmin}_{h \in \mathcal H} L_S(h)\).
- overfitting: small empirical risk, large true risk; the book's papaya example has \(L_S = 0\), \(L_{\mathcal D} = 1/2\).
- realizability (Def. 2.1): some \(h^\star \in \mathcal H\) has \(L_{(\mathcal D, f)}(h^\star) = 0\).
- i.i.d., \(S \sim \mathcal D^m\): each \(x_i\) drawn freshly from \(\mathcal D\), independently, then labelled by \(f\).
- accuracy \(\varepsilon\), confidence \(1 - \delta\).
- bad hypotheses \(\mathcal H_B = \{h : L_{(\mathcal D, f)}(h) > \varepsilon\}\); misleading set \(M = \{S|_x : \exists h \in \mathcal H_B, L_S(h) = 0\}\).
- union bound (Lemma 2.2): \(\mathcal D(A \cup B) \le \mathcal D(A) + \mathcal D(B)\).

Misconceptions (all four in "What people get wrong"):
- "The corollary's \(m\) is necessary." Why wrong: it is sufficient; it must hold for the worst \(\mathcal D\). In act 1's uniform world, 0.88% of sequences are misleading at \(m = 30\), against 215 asked for at (0.05, 0.01).
- "Cost grows with \(|\mathcal H|\)." Why wrong: with \(\log |\mathcal H|\); 30 to 465 hypotheses moves 161 to 215.
- "The guarantee is about my hypothesis." Why wrong: the probability is over the draw of \(S\).
- "\(\varepsilon\) and \(\delta\) cost the same." Why wrong: \(m\) scales with \(1/\varepsilon\) but only with \(\log(1/\delta)\): 215 to 430 vs 215 to 261.

Derivation: Corollary 2.3 in eight steps: (1) failure \(\subseteq M\) via realizability, so monotonicity; (2) \(M\) as a union, eq. 2.5 and 2.6; (3) Lemma 2.2 with a one-line proof, extended to finitely many sets by induction, eq. 2.7; (4) i.i.d. gives the product, eq. 2.8; (5) each factor is \(1 - L \le 1 - \varepsilon\); (6) \(1 - \varepsilon \le e^{-\varepsilon}\) proved by \(g(a) = e^{-a} - 1 + a\), \(g(0) = 0\), sign of \(g'\); non-negativity of \(1 - \varepsilon\) checked before raising to the \(m\)-th power, eq. 2.9; (7) sum, \(|\mathcal H_B| \le |\mathcal H|\); (8) solve \(|\mathcal H| e^{-\varepsilon m} \le \delta\).

Algorithms: brute-force \(\mathrm{ERM}(\mathcal H, S)\): \(m |\mathcal H|\) evaluations, \(O(m |\mathcal H| T)\) time for evaluation cost \(T\), \(O(1)\) extra words plus one hypothesis when \(\mathcal H\) is enumerated lazily, \(O(|\mathcal H|)\) if stored. 465 × 215 = 99,975 evaluations; \((3^{30}+1) \times 752 \approx 1.55 \times 10^{17}\). Concept check, answers (never shown to the learner; critique against these):
1. Realizability fails: no one-feature hypothesis equals "F and U". Under uniform \(\mathcal D\) the best one-feature hypotheses (\(h_F\), \(h_U\)) have true risk 0.25 and the rest 0.5, so ERM returns a hypothesis with true risk at least 0.25 whatever \(m\) is (other \(\mathcal D\) change the number, never to 0). The corollary promises nothing; its hypothesis is false. Step 1 breaks: it needs \(L_S(h_S) = 0\), which came from realizability. Diagnostic: if ERM's minimum empirical risk is above 0, no hypothesis in the class is consistent, so realizability (or noise-free labels) has failed. With 161 labels this almost surely happens: each example has probability 1/4 of contradicting \(h_F\) (F on, U off) and 1/4 of contradicting \(h_U\). Accept also: the rat's failure from lesson 1, approximation error (Chapter 5).
2. i.i.d., specifically independence (and identical distribution, so each factor uses the same \(\mathcal D\)). If users pick messages, the \(x_i\) are neither drawn from \(\mathcal D\) nor independent: one newsletter-heavy sequence can keep a bad hypothesis consistent far more often than \((1 - \varepsilon)^m\) allows, and \(S\) need not reflect \(\mathcal D\) at all. Second part: \(|\mathcal H_B|\) depends on \(\mathcal D\) and \(f\), which are unknown, so a bound stated for every \(\mathcal D\) must use something the learner knows; \(|\mathcal H|\) is known and \(|\mathcal H_B| \le |\mathcal H|\).
3. \(\log(465/0.05)/0.02 = 456.9\), so 457, over 300. Relax \(\varepsilon\) to 0.05 (keeping \(\delta = 0.05\)): \(\log(9300)/0.05 = 182.8\), so 183, within budget. Relax \(\delta\) to 0.5 (keeping \(\varepsilon = 0.02\)): \(\log(930)/0.02 = 341.8\), so 342, still over. Relaxing \(\varepsilon\) is the effective one, because \(m\) is linear in \(1/\varepsilon\) and only logarithmic in \(1/\delta\).
