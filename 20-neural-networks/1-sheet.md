Terms:
- feedforward network: directed acyclic graph \(G = (V, E)\), weight function \(w: E \to \mathbb R\), activation \(\sigma: \mathbb R \to \mathbb R\).
- layers: \(V = V_0 \cup \dots \cup V_T\), disjoint, edges only from \(V_{t-1}\) to \(V_t\); \(V_0\) has \(n + 1\) neurons, the last the constant 1.
- \(a_{t+1,j}(x) = \sum_{r:(v_{t,r},v_{t+1,j}) \in E} w((v_{t,r}, v_{t+1,j}))\,o_{t,r}(x)\), \(o_{t+1,j}(x) = \sigma(a_{t+1,j}(x))\).
- depth \(T\), size \(|V|\), width \(\max_t|V_t|\).
- architecture \((V, E, \sigma)\); class \(\mathcal H_{V,E,\sigma} = \{h_{V,E,\sigma,w} : w: E \to \mathbb R\}\).
- growth function for finite \(\mathcal Y\): \(\tau_{\mathcal H}(m) = \max_{|C| = m}|\mathcal H_C|\).
- backpropagation: forward pass for \(\mathbf a_t, \mathbf o_t\); backward pass \(\boldsymbol\delta_T = \mathbf o_T - y\), \(\delta_{t,i} = \sum_j W_{t,j,i}\delta_{t+1,j}\sigma'(a_{t+1,j})\); partial derivative \(\delta_{t,i}\sigma'(a_{t,i})o_{t-1,j}\).

Misconception: “one hidden layer computes anything, so size doesn’t matter”. Why wrong: universality on \(n\) bits needs \(|E| \ge 2^n/(n + \log_2 e)\) edges.
Second: “label cost grows with neurons”. Why wrong: it grows with edges, \(O(|E|\log|E|)\).
Third: “the VC bound covers sigmoids”. Why wrong: the proof needs finitely many output values per neuron; real-weight sigmoid networks can reach \(\Omega(|E|^2)\); \(b\)-bit weights give \(b|E|\).
Fourth: “SGD finds the best weights”. Why wrong: nonconvex loss; ERM NP-hard even for 3 hidden neurons.
Fifth: “zero initialisation is fine”. Why wrong: symmetric neurons stay identical (snippet: three identical rows after 2,000 steps).
Sixth: “choosing the best of several runs is cheating”. Why wrong: the certificate is uniform over the class.

Derivation:
- Claim (depth 2 universality): \(|V_1| = 2^n + 1\); \(\langle x, u\rangle = n\) iff \(x = u\), else \(\le n - 2\); \(g_i = \operatorname{sign}(\langle x, u_i\rangle - n + 1)\); \(f = \operatorname{sign}(\sum g_i + k - 1)\); the hidden constant made from the input constant with weight 1, unused hidden neurons zeroed.
- Lemma (AND/OR): sums \(k\) or \(\le k - 2\).
- Fact (Turing time \(T(n)\) to size \(cT(n)^2 + b\)): stated, not proved, as in the book.
- Product and composition lemmas: proved in the prose (the book’s Exercises 3 and 4), with the conventions that sets of fewer than \(m\) points get at most \(\tau(m)\) labellings and that \(\tau(m)\) on a domain with fewer than \(m\) points means the count on the whole domain.
- VC theorem: composition over layers, product over neurons, Sauer per neuron with three cases, \(\sum d_{t,i} = |E|\), \(2^m \le (em)^{|E|}\), log lemma with \(\alpha = |E|/\ln 2\), \(\beta = \alpha + 1\): \(\mathrm{VCdim} < 4\alpha\ln(2\alpha) + 2\alpha + 2\).
- Exponential size: \(2^n \le |E|(n + \log_2 e)\), \(|V| \ge \sqrt{|E|}\).
- Certificate: \(|\mathcal H| \le 2^{b|E|}\), lesson 4’s finite-class bound solved for the margin.
- Backpropagation: as in the book, with \(\boldsymbol\delta_t\) named “rate”.

Algorithms: Forward (\(O(|V| + |E|)\) time), Backpropagation (\(O(|V| + |E|)\) time, \(O(|V| + |E|)\) space), SGD for networks (\(O(\tau(|V| + |E|))\) time). Concept check, answers (never shown to the learner; critique against these):
1. With all weights 0, every feature neuron has input 0 and output \(\sigma(0) = 1/2\), and every output weight is 0. Induction: if all feature neurons have identical incoming weights and identical outgoing weights, they have identical \(a\), \(o\); the output-weight gradients \(\delta_2\sigma'(a_2)o_{1,i}\) are identical, so outgoing weights stay identical; \(\delta_{1,i} = W_{1,i}\delta_2\sigma'(a_2)\) is identical, so incoming gradients \(\delta_{1,i}\sigma'(a_{1,i})o_{0,j}\) are identical. So the rows stay equal forever (snippet: three equal rows). (At step 1 the hidden gradients are exactly 0 because the output weights are 0; the output weights move first, equally.) Sign: its derivative is 0 wherever it exists (and undefined at 0), so every gradient through a sign neuron is 0: SGD never moves; this is why training switches to the sigmoid.
2. \(1 \le d \le m\): Sauer \(\sum_{i \le d}\binom mi \le (em/d)^d \le (em)^d\) since \(d \ge 1\). \(m < d\): \(\tau \le 2^m\), and \(2 < e \le em\), so \(2^m < e^m \le (em)^m \le (em)^d\) (needs \(em \ge 1\)). \(d = 0\): one function, \(\tau = 1 = (em)^0\). Breaks for sigmoids: Step 1 and 2 need finite value sets (the growth function counts distinct value lists; with real outputs a single neuron already produces infinitely many), and Step 3 needs the neuron to be a halfspace with VC \(d\). Accept either point; best answers name the finite \(\mathcal Y\) requirement.
3. \(|E| = 20 \cdot 11 + 21 = 241\). Largest \(m\) with \(m \le 241\log_2(em)\): 3,148 (search script in the scratchpad). With 8-bit weights: VC \(\le 8 \cdot 241 = 1{,}928\); labels \(\lceil (1928\ln 2 + \ln 40)/(2 \cdot 0.05^2)\rceil = 268{,}016\). Accept the closed-form log-lemma bound if the learner uses it instead of the search, as long as it is labelled.

Problems (the book’s Exercises 1, 2 and 6, pp. 282 to 283), hint ladders, one rung at a time, never the solution:
- Problem 1 (Exercise 1, universal approximation).
  1. Split \([-1, 1]^n\) into boxes of side \(s\); by Lipschitzness \(f\) varies by at most \(\rho s\sqrt n\) inside a box. Pick \(s\) so that this is at most \(\varepsilon/2\).
  2. A box is an intersection of \(2n\) halfspaces; a sigmoid with large weights approximates the threshold; one AND neuron per box detects “x is in this box” (approximately, away from the faces).
  3. The output layer sums \(f(\text{box centre}) \cdot \mathbb 1[x \in \text{box}]\); handle points near box faces by overlapping boxes or by making the sigmoid steep enough that the error near faces stays under \(\varepsilon/2\) (Lipschitzness again, since neighbouring boxes have close values).
  4. Note the size: \((2/s)^n\) boxes, exponential in \(n\), consistent with Problem 2.
- Problem 2 (Exercise 2, Theorem 20.5).
  1. Given \(f: \{\pm 1\}^n \to \{\pm 1\}\), build a 1-Lipschitz \(g: [-1, 1]^n \to [-1, 1]\) with \(g(x) = f(x)\) at the corners: for instance \(g(x) = \sum_u f(u)\max(0, 1 - \|x - u\|_\infty \cdot c)\)-style bumps around each corner, or a bump of radius 1 around each corner scaled to stay 1-Lipschitz.
  2. If a network approximates \(g\) within \(\varepsilon < 1\), its sign at each corner equals \(f\) there (thresholding the output). So one architecture plus a threshold computes every Boolean function on \(n\) bits.
  3. Use bounded-bit weights (the given fact) so VC \(\le c|E|\); shattering \(2^n\) corners forces \(|E| \ge 2^n/c\), and \(|V| \ge \sqrt{|E|}\).
  4. Careful with the Lipschitz constant of the bumps: corners are distance 2 apart, so bumps of radius 1 and height 1 fit with slope 1.
- Problem 3 (Exercise 6, Theorem 20.7).
  1. Recall lesson 8’s reduction: vertex points \(e_i\) one label, edge points \((e_i + e_j)/2\) the other; a perfect intersection of \(k\) halfspaces exists iff the graph is \(k\)-colourable. (Check which label lesson 8 put on which; the book’s Exercise 32 of Chapter 8 is the source.)
  2. The network with \(k\) hidden sign neurons plus a constant and an AND output contains every intersection of \(k\) halfspaces, so a colouring gives a network with zero empirical risk.
  3. The converse is the real work: a network with zero empirical risk on that sample must yield a colouring. The output is a halfspace over the \(k\) hidden bits, not necessarily an AND; show that the hidden neurons still split the vertices into \(k\) classes with no edge inside a class (an edge point is the midpoint of its two vertex points, so a halfspace that is on one side at both vertices is on that side at the midpoint).
  4. Conclude: ERM with zero empirical risk decides \(k\)-colourability, NP-hard for \(k \ge 3\).
