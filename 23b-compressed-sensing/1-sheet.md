# Compressed Sensing

Objective: after this, you can explain why no recovery matrix can undo a squeeze even for one-word messages, so the decoder must be nonlinear; define sparsity and the RIP, prove that RIP for \(2s\) makes \(\ell_0\) decoding exact and that RIP with \(\varepsilon < 1/(1+\sqrt2)\) makes \(\ell_1\) decoding (a linear program) exact for sparse and stable for almost-sparse vectors; prove that Gaussian matrices are RIP with \(n = O(s\ln(d/\varepsilon)/\varepsilon^2)\) rows; compute the RIP constant of a unit-column matrix for \(2s = 2\) as its largest column dot product; choose between PCA and compressed sensing by their assumptions; and certify a small desk by a result of the lesson rather than by test messages.

Key words: message (not "document", "email"), watchlist, word count, squeeze (not "embed", "encode" outside the pseudocode), compression matrix \(W\), recovery matrix \(U\), recovered message \(\tilde x\), decoder (any rule from stored numbers to a message; the recovery matrix is the linear one), smear (the shortest-message decoder's output on a one-word message), null space, s-sparse, \(\|x\|_0\), RIP / RIP constant, \(\ell_1\) norm, linear program, net (not "cover", "epsilon-net" after definition), certified (a result of the lesson covers it) against measured (these test messages), house rules.

Terms:
- watchlist: the six flagged words free, prize, winner, urgent, claim, wire, in that order (indices 0 to 5).
- decoder: a rule \(y \mapsto \tilde x\); linear decoders are recovery matrices \(U\).
- shortest matching message: \(\operatorname{argmin}_{Wv = y}\|v\|\); for the icosahedron \(W\), \(\frac12 W^\top y\) because \(WW^\top = 2I\).
- \(\|x\|_0\): number of nonzero entries; s-sparse: \(\|x\|_0 \le s\).
- \((\varepsilon, s)\)-RIP: \(|\|Wx\|^2/\|x\|^2 - 1| \le \varepsilon\) for all nonzero s-sparse \(x\); RIP constant: the smallest such \(\varepsilon\).
- \(\ell_1\) norm \(\|v\|_1 = \sum |v_i|\); \(x_s\): best s-term approximation; \(\ell_1\) program: \(\min \sum t_i\) such that \(Wv = y\), \(-t_i \le v_i \le t_i\).
- net: a finite set of unit vectors within distance \(\varepsilon\) of every unit vector.
- for unit columns and \(2s = 2\): the RIP constant is \(\max_{i \ne j} |w_i \cdot w_j|\) (the \(2 \times 2\) dot-product table has eigenvalues \(1 \pm |c|\)).

Misconception: "a better recovery matrix would fix the smear". Why wrong: right on every one-word message makes it right on every message (messages are sums of \(e_j\), matrices respect sums), and the null space forbids that.
Second: "exact recovery of a squeezed message is impossible". Why wrong: impossible for every message; possible for every sparse one when the null space has no sparse vector.
Third: "the linear program recovered my test messages, so the matrix is fine". Why wrong: success on tests is not a guarantee; icosahedron: 30 of 30 and 0.447 above 0.414, and some two-word messages share their stored numbers.
Fourth: "the RIP theorem's constants say how many measurements you need". Why wrong: 216 comes from a crude proof; at the mail room's size it asks for 2.49 million rows.

Concept check, answers (never shown to the learner; critique against these):
1. The sparsest result needs \((\varepsilon, 2s)\)-RIP with \(\varepsilon < 1\); with \(2s = 2\) the matrix qualifies, so \(s = 1\). For \(s = 2\) it needs \((\varepsilon, 4)\)-RIP with \(\varepsilon < 1\). The first four columns \((0, a, \pm a, \pm a)\) all have first coordinate 0, so they live in a 3-dimensional space and are dependent: \(c_0 - c_1 - c_2 + c_3 = 0\) (with the lab's order \(c_0 = (0,a,a,a)\), \(c_1 = (0,a,a,-a)\), \(c_2 = (0,a,-a,a)\), \(c_3 = (0,a,-a,-a)\)). So the nonzero 4-sparse \(v = (1, -1, -1, 1, 0, 0)\) has \(Wv = 0\), the squared ratio is 0, and the constant for four columns is exactly 1 (computed 1.0): the result does not apply. Twins: "free once and urgent once" and "prize once and winner once" both store \((0, 1.1547, 0, 0)\) (\(c_0 + c_3 = c_1 + c_2\)). A decoder is a function of the stored numbers, so it returns one answer for both and is wrong on at least one. Accept any dependent four columns with the right signs.
2. \(x_s = (0,0,0,5,0,0)\), \(\|x - x_s\|_1 = 1\), \(s^{-1/2} = 1\). At \(\varepsilon = 0.408\): \(\rho = \sqrt2 \cdot 0.408/(1 - 0.408) \approx 0.975\), \(C = 2(1+\rho)/(1-\rho) \approx 156\) with the rounded 0.408 and 162.4 with the exact 0.40825 (the constant is extremely sensitive near the threshold; accept 150 to 165): \(\|x^\star - x\|_2 \le C\) while \(\|x\|_2 = \sqrt{26} = 5.1\), so the promise is true and useless (it allows an error thirty times the message). At \(\varepsilon = 0.2\): \(\rho = 0.354\), \(C = 4.19\): still weak (an error of up to 4.19 on a message of length 5.1), but meaningful. Computed outputs: the four-row matrix returns urgent 4, claim 0.816, wire \(-0.816\), error 1.826; the five-row and icosahedron matrices return it exactly. Good answers say that the guarantee for almost-sparse messages is much weaker than for exactly sparse ones near the threshold.
3. Both claims are true and consistent. Tests: 2,000 random one-word messages gave 0 failures, so the program works on what was tried. The result: the lesson's theorem needs \((\varepsilon, 2)\)-RIP with \(\varepsilon < 0.414\), the icosahedron has 0.447, so the theorem says nothing about it (and a bigger test set would not change that: the mail room's messages number \(\binom{50000}{60}\) supports times counts, so tests cannot cover them). Neither claim says the matrix fails; in fact for one-word messages the program is exact for any pairwise non-parallel unit columns (a fact beyond the lesson, see Assumptions), but nothing in the lesson proves it, and for two-word messages the icosahedron has twins, so no decoder is exact there. To ship with a certificate, use a matrix whose constant is below 0.414 (the four-row design, 0.408, with four numbers), or an arrangement the lesson's theorem covers. Look for "tests are not a guarantee" and for the exact threshold comparison, not for "the icosahedron fails".

End-of-chapter problem (new in the split; the book's exercises are all for lesson 23a). In the prose: Problem 1 (at least \(2s\) numbers). Hints one rung at a time; never the solution.
- Problem 1: \(W \in \mathbb R^{n,d}\) with \(n < 2s \le d\); show two different s-sparse vectors with the same \(Wx\).
  1. Pick any \(2s\) columns of \(W\). They are \(2s\) vectors in \(\mathbb R^n\) and \(n < 2s\).
  2. More vectors than dimensions: they are linearly dependent, so some nonzero \(v\), nonzero only on those \(2s\) positions, has \(Wv = 0\) (\(n\) equations, \(2s\) unknowns, as in lesson 23a's null-space argument).
  3. Split the \(2s\) positions into two sets \(I\) and \(J\) of \(s\) positions each, and write \(v = v_I + v_J\).
  4. \(Wv_I = -Wv_J\), so \(a = v_I\) and \(b = -v_J\) have \(Wa = Wb\); both are s-sparse. They differ: if \(a = b\) then \(v_I = -v_J\), but their supports are disjoint, so both are 0 and \(v = 0\), a contradiction.
  5. A decoder returns one vector for the stored \(Wa = Wb\), wrong on \(a\) or on \(b\). Check: the icosahedron has \(n = 3 < 4 = 2s\) for \(s = 2\), and the twin is free 1 + claim 1 against prize \(\varphi\) + winner \(\varphi\). Remark: \(n \ge 2s\) is necessary, and the lesson's results need far more (order \(s \ln d\)).

Assumptions:
- Every claim from the book was checked by the original writer against the PDF (pp. 330 to 338); no separate book-check agents were run (CPU rule).
- Lemma 23.11's proof in the book counts grid points by a volume ratio, which is a heuristic, not a proof. The lesson replaces it by the standard greedy packing argument, \(|N| \le (1 + 2/\varepsilon)^s\), with net points on the sphere (so JL never sees a zero vector); the book's \((3/\varepsilon)^d\) bound is the same up to constants. Volume of a ball \(c_s r^s\) used without proof.
- Theorem 23.9: the book states \(n \ge 100\, s\log(40d/(\delta\varepsilon))/\varepsilon^2\) but its sketched proof (Lemma 23.12, then \((1-2\varepsilon) \le \|Wx\|^2 \le (1+3\varepsilon)\), then a union bound) does not give that constant: the squared bounds need a rescaling to \(\varepsilon/3\).
